W65C816 + RP2350 Computer Design Overview
==========================================

This repository contains a two-board 3.3 V W65C816 computer.

- The mainboard is the real 65C816 computer: CPU, RAM, ROM, address decode,
  expansion bus, power entry, and socketable glue logic.
- The RP2350 daughterboard is the modern I/O and media board: video, audio,
  USB, storage, networking, and dense/high-speed circuitry.

The design goal is to keep user applications and game logic running as real
65C816 machine code, while the RP2350 behaves like a hardware chipset.

System Concept
--------------

The mainboard exposes a 24-bit address bus and 8-bit data bus from the
W65C816. Main SRAM and boot Flash sit directly on that bus behind address
decoding and glue logic. The RP2350 daughterboard appears to the W65C816 as a
memory-mapped I/O device.

High-level block diagram:

W65C816 CPU
  -> 24-bit address bus / 8-bit data bus
  -> SRAM and boot Flash
  -> address decoding / glue logic
  -> RP2350 daughterboard memory-mapped interface
  -> video, audio, USB, storage, networking, debug, GPIO

The RP2350 is responsible for:

- graphics processing
- audio processing
- USB host support
- SD-card storage
- Ethernet and WiFi offload interfaces
- debugging interface
- general-purpose I/O


Mainboard
=========

Mainboard Design Rules
----------------------

- Main logic voltage: 3.3 V.
- Prefer through-hole and socketable components wherever practical.
- CPU, memory, oscillator, and important glue logic should be socketed.
- Mainboard glue logic should use 74HC-family DIP parts.
- Do not use 5 V-only logic parts without explicit review.
- Every IC needs local 100 nF decoupling.
- Flash write-enable must default to disabled.
- HDMI, USB high-speed routing, RP2350, and dense modern circuitry belong on
  the daughterboard.


1. CPU Subsystem
----------------

Purpose:

The W65C816 multiplexes bank address bits A16-A23 onto D0-D7 during part of
the bus cycle. The bank-address latch captures these bits so the rest of the
system sees a stable 24-bit address bus.

The first board should run at 8 MHz. The oscillator is socketed so faster
clock modules can be tested later.

Components:

| Reference | Function                 | Suggested Part        | Package |
|-----------|--------------------------|-----------------------|---------|
| U1        | Main CPU                 | W65C816S6PG-14        | DIP-40  |
| X1        | CPU clock oscillator     | 8 MHz CMOS oscillator | DIP-14  |
| U2        | Bank-address latch       | 74HC573N              | DIP-20  |
| U3        | CPU data transceiver     | 74HC245N              | DIP-20  |
| U4        | Reset supervisor         | MCP100 or MCP130      | TO-92   |
| U5        | Reset conditioning       | 74HC14N               | DIP-14  |
| SW1       | Reset button             | Momentary switch      | THT     |
| SW2       | NMI button               | Momentary switch      | THT     |

Main CPU signals:

4. Address Decode and Glue Logic
--------------------------------

Address decoding generates SRAM, ROM, RP2350, expansion, and I/O chip-select
signals. Not every spare gate must be used in revision A, but the schematic can
include common glue packages so spare gates are available.

Components:

| Reference | Function                | Suggested Part | Package |
|-----------|-------------------------|----------------|---------|
| U6        | Main address decoder    | 74HC138N       | DIP-16  |
| U7        | SRAM-bank decoder       | 74HC138N       | DIP-16  |
| U8        | I/O decoder             | 74HC139N       | DIP-16  |
| U9        | NAND gates              | 74HC00N        | DIP-14  |
| U10       | Inverters               | 74HC04N        | DIP-14  |
| U11       | AND gates               | 74HC08N        | DIP-14  |
| U12       | OR gates                | 74HC32N        | DIP-14  |
| U13       | Flip-flops              | 74HC74N        | DIP-14  |
| U14       | Tri-state buffers       | 74HC125N       | DIP-14  |
| U15       | Address/control buffer  | 74HC541N       | DIP-20  |
| U16       | RP2350 data transceiver | 74HC245N       | DIP-20  |

Generated chip-select and control signals:

- /RAM_CS0 through /RAM_CS7
- /ROM_CS
- /RP_CS
- /EXP_CS
- /IO_CS
- /IO_RD
- /IO_WR

Revision A boot decode:

- U7 divides the low 4 MB memory space into eight 512 KB SRAM windows.
- U20-U27 use /RAM_CS0 through /RAM_CS7 for up to 4 MB fitted SRAM.
- U6 detects bank $00 within the low SRAM window.
- Boot Flash overlays $00:8000-$FFFF so reset vectors are reachable.
- RAM0 is disabled while the boot Flash window is active.
- /OE and /WE are derived from R/W.

9. Mainboard Power
------------------

The final mainboard should accept 5 V through a through-hole DC input connector
rated for at least 5 A. PJ-102AH is the selected 5 A barrel jack for the
mainboard input.

The mainboard protects and distributes the 5 V rail, then generates the main
3.3 V logic rail with a socketed buck module.

Recommended power path:

5 V DC input -> fuse -> power switch -> reverse-polarity protection ->
protected +5V rail -> 3.3 V buck module and daughterboard power feed

Components:

| Reference | Function                    | Suggested Implementation |
|-----------|-----------------------------|--------------------------|
| J4        | 5 V input                   | CUI PJ-102AH, 5 A-rated THT barrel jack |
| F1        | Input fuse                  | 5 A replaceable fuse or appropriately derated polyfuse |
| SW3       | Main power switch           | High-current external or THT switch |
| Q1        | Reverse-polarity protection | P-channel MOSFET, TO-220 |
| D1        | Input transient protection  | 5 V TVS diode            |
| MOD1      | 3.3 V regulator             | Socketed buck module, 3 A minimum |
| C40       | 5 V bulk capacitance        | 470 uF electrolytic      |
| C41       | 5 V local bypass            | 100 nF ceramic           |
| C42       | 3.3 V bulk capacitance      | 470 uF electrolytic      |
| C43       | 3.3 V local bypass          | 100 nF ceramic           |
| LED1      | Power LED                   | THT LED                  |
| R41       | LED resistor                | 1 kΩ to 2.2 kΩ           |
| TP23      | 5 V test point              | THT test point           |
| TP24      | 3.3 V test point            | THT test point           |
| TP25      | Ground test point           | THT test point           |

Power rails:

- +5V_IN: raw DC input.
- +5V_FUSED: after the input fuse.
- +5V_SW: after the main switch.
- +5V: protected 5 V rail.
- +3V3: regulated main logic rail.
- GND: common system ground.

Current planning:

- Use PJ-102AH as the 5 A-rated input connector for the final board.
- The RP2350 daughterboard can contain several USB-A ports. Three to four USB
  ports can draw 1.5-2.0 A before the daughterboard electronics are counted.
- The daughterboard must not connect USB-A VBUS directly to +5V. Use one
  current-limited load switch per USB-A port, with local ESD protection.
- The 5 V and GND pins between the mainboard and daughterboard should use
  multiple parallel contacts to reduce voltage drop.
- If the final system must support several high-current USB devices at once,
  consider a higher-current power connector or a separate daughterboard power
  input.


RP2350 Daughterboard
====================

Daughterboard Design Rules
--------------------------

- The daughterboard may use SMD components where required.
- HDMI/DVI, USB, RP2350, high-speed memory, and dense circuitry live here.
- Follow Raspberry Pi RP2350 reference design guidance for the RP2350 core,
  crystal, flash, power rails, RUN, BOOTSEL, and SWD.
- Route USB as 90 Ω differential pairs.
- Keep HDMI/DVI high-speed routing entirely on the daughterboard.

-------------------------

Rear panel:

- DVI/HDMI connector
- RJ45 Ethernet
- power jack, if mechanically placed on rear panel

Front panel:

- USB-A port 2
- full-size SD card
- power/reset controls

The exact board-edge assignment may change during mechanical layout, but this
front/rear split is the current target.

6. USB Host
-----------

Use the RP2350B native USB D+/D- pins as the upstream connection to a dedicated
4-port USB 2.0 hub IC.

Recommended hub IC options:

- CH334
- SL2.1A
- FE1.1s, SSOP-28

USB architecture:

- The USB hub and all USB-A connectors live on the daughterboard.
- Use direct PCB-mounted USB-A receptacles, not wire harnesses.
- Route USB data lines as tightly coupled 90 Ω differential pairs.
- Keep USB data traces on one layer where practical and avoid vias.
- Place ESD protection directly behind every USB-A connector.

Power rules:

- Do not wire USB-A VBUS pins directly to +5V.
- Use a load switch or power distribution switch per USB-A port.
- Suitable examples include AP2011 or SY6280 class parts.
- Provide local VBUS bulk capacitance for the USB port group.
- Three to four USB ports may draw 1.5-2.0 A total.

Components:

| Reference | Function              | Suggested Part |
|-----------|-----------------------|----------------|
| U6        | USB 2.0 hub           | CH334, SL2.1A, or FE1.1s |
| J6-J9     | USB-A connectors      | THT or hybrid USB-A |
| Ux        | USB load switches     | AP2011, SY6280, or equivalent |
| Ux        | USB ESD protection    | USBLC6-2SC6 or equivalent |
| R-series  | USB damping/series    | As recommended by hub datasheet |
| Cx        | VBUS bulk capacitance | 47-100 uF minimum per group |


7. Storage
----------

Use a full-size SD card socket on the daughterboard.

Revision A should use 4-bit SDIO through RP2350 PIO rather than SPI mode. A
14 MHz 65C816 bus cannot consume storage data fast enough to justify a separate
storage MCU; the RP2350 can handle SDIO and present buffered data to the 65C816
through registers or FIFOs.

Components:

| Reference | Function        | Suggested Implementation |
|-----------|-----------------|--------------------------|
| J10       | SD card socket  | Full-size SD preferred   |
| Ux        | ESD protection  | Optional, near socket    |
| R-pull    | Signal pull-ups | 10 kΩ                    |
| R-series  | Signal damping  | 22-47 Ω                  |
| Cx        | Local bulk      | 10 uF                    |
| Cx        | Decoupling      | 100 nF                   |


8. Networking
-------------

Networking is offloaded so the RP2350 does not spend large amounts of time in
software network stacks.

WiFi:

- Use an ESP32-C3 module pre-flashed with AT command firmware.
- Communicate with it over SPI.
- Keep the wireless network stack off the RP2350.

Ethernet:

- Use a WIZnet W5500 IC or module.
- W5500 provides Ethernet MAC, PHY, and hardwired TCP/IP offload.
- Communicate with it over SPI.

Components:

| Reference | Function         | Suggested Implementation |
|-----------|------------------|--------------------------|
| Ux/MODx   | WiFi offload     | ESP32-C3 AT module       |
| Ux        | Ethernet offload | WIZnet W5500             |
| Jx        | RJ45 connector   | Integrated magnetics preferred |
| LEDx      | Link/activity    | Optional                 |

general ARM computer. The W65C816 sends compact commands and data structures
through memory-mapped registers and FIFOs.

Development Stages
==================

Stage 1: CPU Boot
-----------------

Populate only:

- W65C816
- clock oscillator
- bank-address latch
- eight SRAM sockets, with only U20 required to be populated for bring-up
- boot Flash
- address decoder
- reset circuit
- debug header
- 5 A-rated mainboard power input and 3.3 V regulator

Goal:

- fetch reset vector
- execute ROM code
- write known patterns to SRAM
- output status through GPIO or debug port


Stage 2: RP2350 Register Interface
----------------------------------

Add:

- J1/J2 board-to-board connectors
- RP2350 daughterboard
- data transceiver
- address/control buffer
- simple status and command registers

Goal:

- W65C816 writes a byte to RP2350 register space
- RP2350 receives it
- RP2350 returns a byte
- IRQ signalling works


Stage 3: Video
--------------

Add:

- DVI/HDMI output
- basic framebuffer
- text console
- 320 x 240 indexed bitmap mode
- revision A minimum video modes

Goal:

- display boot messages
- display memory test results
- draw tiles and sprites


Stage 4: Storage and Input
--------------------------

Add:

- SDIO full-size SD card
- USB hub
- USB keyboard
- USB mouse
- USB HID gamepads


Stage 5: Audio and Networking
-----------------------------

Add:

- PCM5102A audio module or equivalent
- synthesizer/audio engine
- W5500 Ethernet
- ESP32-C3 WiFi offload module
