The mainboard contains the real W65C816 CPU, RAM, ROM, address decoding, expansion bus and socketable glue logic.
The daughterboard contains the RP2350B, HDMI/DVI output, USB, graphics memory and modern high-speed components.

All user applications and game logic run as real 65C816 machine code on the physical W65C816.
The RP2350 acts as:
- graphics processor
- audio processor
- USB controller
- storage controller
- networking controller
- debugging interface
- general-purpose I/O controller

2. Mainboard
2.1 CPU subsystem
Components
Reference	Component	Suggested part	Package
U1	Main CPU	W65C816S6PG-14	DIP-40
X1	CPU clock oscillator	8 MHz CMOS oscillator	DIP-4
U2	Bank-address latch	74HC573N	DIP-20
U3	CPU data transceiver	74HC245N	DIP-20
U4	Reset supervisor	MCP100 or MCP130	TO-92
U5	Reset signal conditioning	74HC14N	DIP-14
SW1	Reset button	Momentary push button	THT
SW2	NMI button	Momentary push button	THT


Purpose
The W65C816 multiplexes address bits A16–A23 onto D0–D7 during part of the bus cycle. U2 latches those upper address bits so the system has a stable 24-bit address bus.
The first board should run at 8 MHz. The oscillator is socketed so faster clock modules can later be tested.

4. Software-visible hardware model
The RP2350 should behave like a hardware chipset rather than a general ARM computer.
The W65C816 sends compact commands and data structures.

5. Initial development stages
Stage 1: CPU boot
Populate only:
- W65C816
- clock oscillator
- bank-address latch
- one SRAM
- boot flash
- address decoder
- reset circuit
- debug header
Goal:
Fetch reset vector
Execute ROM code
Write known patterns to SRAM
Output status through GPIO or debug port
Stage 2: RP2350 register interface
Add:
- J1/J2 connectors
- RP2350 daughterboard
- data transceiver
- address/control buffer
- simple status and command registers
Goal:
W65C816 writes a byte
RP2350 receives it
RP2350 returns a byte
IRQ signalling works
Stage 3: video
Add:
- HDMI output
- basic framebuffer
- text console
- 320 × 240 indexed mode
Goal:
Display boot messages
Display memory test results
Draw tiles and sprites
Stage 4: storage and input
Add:
- SD card
- USB keyboard
- gamepad support
Stage 5: audio and networking
Add:
- PCM5102A
- synthesizer
- W5500 Ethernet
